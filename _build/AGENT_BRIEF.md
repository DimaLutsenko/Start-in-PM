# Бриф для агентів: курс «Продакт з нуля»

Курс продакт-менеджменту для новачків українською. 12 тижнів × 3 уроки (уроки X-1 і X-2 — теорія, X-3 — практика). Сайт: статичний HTML на GitHub Pages, репозиторій `/home/claude/start-in-pm`. Мета зараз: зробити курс **максимально читабельним, цікавим і зрозумілим** для людини без досвіду, і **фактично бездоганним**.

## Як влаштовані файли

- `lessons/<id>.html` — **згенеровані** файли. Не редагуй їх руками: їх перезаписує збірка.
- `_build/orig/<id>.html` — джерело тексту уроку (старий формат, секції `<section id="...">` усередині `article.lesson-body`). Текст правиш тут.
- `_build/V2/<id>.html` — шаблон екранів. Перший рядок — JSON-мета в коментарі. Далі `<section class="screen" id=".." data-step="0..4" data-name="..">`. Усередині — твій HTML і директиви `<take sel="#секція" i="1-3"></take>` (вставляє дітей секції оригіналу з індексами 1..3; h2 має індекс 0) або `<take sel="CSS-селектор"></take>` (вставляє самі елементи).
- Зібрати урок: `cd /home/claude/start-in-pm && python3 _build/v2build.py 02-1 02-2` .
- **Ніколи не запускай `_build/v2auto.py`** — він перезапише шаблони з нуля.
- Перевірити: `python3 _build/v2smoke.py 02-1 02-2` (усі екрани на 1280 і 390 px: помилки JS, вилізання по ширині, кількість питань тесту). Має бути `errs [] overflow []`.
- Скріншот екрана для себе: `python3 _build/shots.py 02-1 <id-екрана>,<id> 1280` → PNG у `/tmp/claude-0/-home-claude/a5d13250-5372-5fde-ae2c-2b2ff6cb63f0/scratchpad/shots/` (переглянь через Read).
- **Еталон формату — тиждень 1**: `_build/V2/01-1.html` (найкращий), `01-2.html`, `01-3.html`. Прочитай 01-1 повністю перед роботою.
- **Не чіпай** спільні файли: `assets/*.css`, `assets/*.js`, `index.html`, `program.html`, `product.html`, `zoshyt.html`, `assets/course.js`. Не роби git commit/push — це робить координатор. Не чіпай уроки, які тобі не призначені.

## Доступні компоненти (вже є в assets/v2.css і stepper.js)

- `<div class="main-idea"><p><b>Головне.</b> …</p></div>` — жовтий стікер з головною думкою. Часто в парі із заголовком: `<div class="head-row"><div><span class="eyebrow">…</span><h2>…</h2></div><div class="main-idea">…</div></div>`.
- `<div class="ex"><span class="label">У «Слоті»</span><p>…</p></div>` — приклад зі «Слота» (зелений). Маленькі картки: `<div class="ex mini"><b>…</b><span>…</span></div>`.
- `<div class="fact"><span class="label">Цікаво знати</span><p>…</p></div>` — факт/історія (фіолетовий).
- `<div class="warn"><span class="label">Пастка</span><p>…</p><span class="fix"><b>Як правильно:</b> …</span></div>` — типова помилка (помаранчевий).
- `<div class="card">`, `<b class="t">` — картка; `card edge-blue|edge-green|edge-orange`; сітки `grid-2 / grid-3 / grid-4 / grid-6`; `split` — дві колонки; `chips` + `chip blue|green|orange`.
- `<details class="more"><summary>Детальніше: …</summary><div>…</div></details>` — сховати подробиці.
- Сцена-чат: `<div class="chat"><div class="msg"><span class="ava p-andrii">А</span><div><span class="who">Андрій · CEO</span><span class="bubble">…</span></div></div>…</div>`. Аватари: `p-andrii p-viktor p-olena p-oleh p-serhii p-marta p-you` (для інших персонажів можна `p-oleh` з іншою літерою).
- Міні-перевірка з поясненням (зберігає вибір):
```
<div class="self-check pick" id="pick-УНІКАЛЬНИЙ" data-yes="Так." data-nope="Не зовсім.">
  <span class="label">Перевір себе</span>
  <p class="pick-q">Питання…</p>
  <div class="pick-opts">
    <button type="button" class="pick-opt" data-ok="1" data-say="Пояснення правильної.">Варіант</button>
    <button type="button" class="pick-opt" data-say="Чому ні.">Варіант</button>
  </div>
  <div class="pick-out" hidden></div>
</div>
```
  Без рамки (у сцені): `<div class="pick" …>`.
- Вкладки: контейнер `.tabs`, кнопки `[data-tab="x"]`, панелі `[data-panel="x"]`.
- Рубрика самоперевірки для практики (обов'язково до кожного практичного завдання):
```
<details class="more"><summary>Самоперевірка: як виглядає слабка і сильна відповідь</summary><div>
  <div class="grid-2">
    <div class="warn"><span class="label">Слабо</span><p>Приклад слабкої відповіді…</p><p>Чому слабо…</p></div>
    <div class="ex"><span class="label">Добре</span><p>Приклад сильної відповіді…</p><p>Чому добре…</p></div>
  </div>
  <ul><li>Критерій перевірки…</li></ul>
</div></details>
```
- Поля зошита (`[data-field]`), тести (`#quiz` + скрипт), калькулятори, матриці — **не ламай**: id полів, `data-field`, `#quiz` і скрипти мають лишитися як є, бо там збережені відповіді учнів.

## Стандарт якості (що означає «читабельно, цікаво, зрозуміло»)

1. **Кожен теоретичний екран** починається з «Головне» (стікер, 1–2 речення), далі пояснення простими словами, далі приклад. Абстракція без прикладу — помилка.
2. **Кожна складна ідея** має приклад зі «Слота» (блок `.ex`) — реалістичний, з людьми команди, узгоджений з цифрами вище.
3. **На уроці X-1 і X-2**: щонайменше одна сцена-чат з командою «Слота» (на екрані кроку 2 «На прикладі «Слота»») з вибором «Твій хід» (`.pick`), і 2–3 міні-перевірки «Перевір себе» на екранах кроку 1. Питання мають перевіряти розуміння, а не пам'ять; пояснення — до кожного варіанту.
4. **Довгі абзаци** розбивай. Речення коротші. Терміни пояснюй при першій появі. Без канцеляриту. Звертання на «ти».
5. **Довгі відступи/історії/деталі** — у `details.more` або `.fact`, щоб основна лінія читалась швидко.
6. **Практика (X-3 і завдання в X-1/X-2)**: кожне завдання має рубрику самоперевірки (див. вище). Кроки завдання — чіткі, з прикладом заповнення там, де це допомагає.
7. **Мова**: природна українська. Без русизмів і калік («приймати участь», «на протязі», «співпадати», «вірно» замість «правильно», «слідуючий», «являється» тощо), без змішаних латинських літер у кирилиці. Лапки «», тире —, нерозривні пробіли там, де вони вже є.
8. **Факти** (історія, люди, компанії, книги, дослідження, статистика, цитати): кожен перевір через WebSearch/WebFetch. Неправильне — виправ. Неперевірне — пом'якш формулювання або прибери. Цитати: якщо точне формулювання не знайдено, переказуй своїми словами без лапок або вкажи «за словами…». Назви книг — оригінальні англійські, якщо немає надійного українського перекладу.
9. Не роздувай: мета — ясність, а не обсяг. Не дублюй той самий текст двічі на екрані.
10. Блоків «Кейс з практики» в курсі зараз немає — не додавай їх.
