# Збірка уроків

Папка не публікується (Jekyll пропускає теки з «_»).

- `orig/` — уроки в старому форматі, джерело тексту.
- `V2/` — шаблони екранів: тиждень 1 написаний вручну, решта згенерована `v2auto.py`.
- `python3 v2build.py 01-1` — зібрати урок із шаблону.
- `python3 v2auto.py 06-2` — згенерувати шаблон зі старого уроку і зібрати.
