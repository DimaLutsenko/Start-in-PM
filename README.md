# Продакт з нуля

Курс продакт-менеджменту: 12 тижнів, 36 уроків. Статичний сайт для GitHub Pages.

## Структура
- `index.html` — головна
- `program.html` — програма курсу
- `product.html` — вигаданий продукт «Слот» для практики
- `lessons/WW-N.html` — уроки (тиждень-номер)
- `assets/course.js` — структура курсу (назви уроків, тижні, артефакти), прогрес, навігація
- `assets/style.css` — стилі

Назви і описи уроків змінюються в `assets/course.js`. Коли урок готовий, додай йому `status: "ready"` і прибери тег «чернетка» в HTML уроку.

## Публікація на GitHub Pages
1. Створи репозиторій, наприклад `pm-course`, і завантаж у нього всі файли.
2. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, папка `/ (root)`.
3. Сайт буде доступний за адресою `https://<username>.github.io/pm-course/`.

Прогрес зберігається в localStorage браузера, без реєстрації.
